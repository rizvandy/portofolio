Tentang Saya

Latar belakang pendidikan dan fokus pengembangan keahlian

Saya adalah seorang mahasiswa program studi S1 Teknik Informatika di Universitas Dr. Soetomo yang memiliki ketertarikan tinggi pada dunia teknologi informasi dan pengembangan perangkat lunak web.

Saat ini, saya berfokus pada pemantapan keahlian Frontend Development menggunakan HTML5, CSS3, JavaScript, dan framework CSS seperti Bootstrap. Pada saat yang sama, saya juga sedang secara aktif mempelajari dasar-dasar Backend Development untuk memahami arsitektur web secara utuh.

Tujuan jangka panjang saya adalah berkembang menjadi seorang Full Stack Developer yang kompeten. Saya sangat antusias untuk mendapatkan pengalaman magang profesional di industri serta memperluas jaringan komunikasi dengan sesama praktisi teknologi.

Selain kemampuan teknis, saya juga aktif mengembangkan soft skills seperti komunikasi, kerja sama tim, dan manajemen waktu. Saya yakin kombinasi hard skill dan soft skill adalah kunci sukses di industri teknologi.
